# Marketing Automation System

A responsive, interactive frontend-based Marketing Automation System developed as part of an internship project.

## 🌐 Live Demo

**Live Website:** https://marketing-automation-system-umber.vercel.app/

**GitHub Repository:** https://github.com/Yamina-a11y/marketing-automation-system

## 📌 Project Overview

The Marketing Automation System is a web-based dashboard designed to simplify marketing activities by providing a centralized platform for managing campaigns, subscribers, email templates, automation workflows, landing pages, analytics, and reports.

The project demonstrates the functionality and user interface of a marketing automation platform using sample data and browser-based storage.

## ✨ Features

- **Dashboard:** Overview of campaigns, subscribers, and marketing statistics.
- **Campaign Management:** Create, edit, delete, search, and filter campaigns.
- **Email Templates:** Manage reusable email templates and preview designs.
- **Subscriber Management:** Add, search, activate, deactivate, and delete subscribers.
- **Campaign Analytics:** View campaign performance and simulated engagement metrics.
- **Automation Workflows:** Create and manage marketing automation workflows.
- **Landing Pages:** Manage sample marketing landing pages.
- **Reports:** View reports and export campaign or subscriber data as CSV.
- **Dark Mode:** Switch between light and dark themes.
- **Responsive Design:** Interface adapts to desktop, tablet, and mobile screens.
- **Simulated Login:** Demonstrates a basic login interface.

## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and responsive layouts
- JavaScript – Interactive functionality
- LocalStorage – Browser-based data persistence
- Vercel – Deployment and hosting
- Git & GitHub – Version control

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Yamina-a11y/marketing-automation-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd marketing-automation-system
   ```

3. Open the folder in Visual Studio Code.

4. Install the Live Server extension.

5. Right-click `index.html` and select **Open with Live Server**.

### Deployment

The application is deployed using Vercel and can be accessed through the live demo link provided above.

## 💾 Data Storage

The application uses sample data and browser LocalStorage to demonstrate data management and persistence.

Data is stored locally in the browser and is not connected to a backend database.

## ⚠️ Project Limitations

- No backend server or database integration.
- Email campaigns are not actually sent.
- Analytics are simulated using sample data.
- Login is a frontend demonstration and does not provide real authentication.
